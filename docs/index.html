One coinslot for the whole shop.

Slotify is a free, open-source all-in-one timer and coinslot for Windows pisonet and rental shops. One coin box at the counter runs your Windows PCs, Android tablets and phones: customers tap Insert Coin, drop the coin, and the time goes straight to their PC, tablet or phone.

How it works

Tap, drop, play.

One shared coin box at the counter serves every unit. No coinslot or timer board on each PC.

Tap Insert Coin

The customer taps the button on their locked PC or tablet. It shows the price ladder.

The slot opens

The server reserves the coinslot for that unit and the slot lights up. Everyone else sees "slot in use".

Drop coins

₱1, ₱5, ₱10 or ₱20, as many as they like within 60 seconds. Then tap DONE.

Time is added

The unit unlocks with the time. When it runs out, it locks again and mutes the audio.

Features

What you get, free.

One coinslot, every unit

A single central coin box serves all PCs, tablets and phones. Fewer coin acceptors to buy, wire and fix.

One server screen

See every station, its status and remaining time. Add, remove or transfer time from the counter.

Tablets as rental units

Android phones and tablets run in locked kiosk mode. Customers can't exit the app for free time.

Prices in one place

Change rates once on the server and every unit updates instantly. Separate prices for PCs and tablets.

Sales log you can trust

Every coin, admin credit and price change is recorded in a tamper-evident log, with CSV export.

No internet needed

Runs on your shop network only. PCs and the coin box find the server by themselves.

Anti-daya

Built so coins don't go missing.

The coin box was tested against noise, power cuts and Wi-Fi drops in a working shop.

  • The slot is physically lockedCoins bounce back unless someone has tapped Insert Coin.
  • Fails safeIf the box loses power or restarts, the acceptor rejects coins instead of swallowing them.
  • Pitik and spark protectionAn optocoupler and filtering ignore fake pulses from lighters and electrical noise.
  • Coins survive outagesEach coin is saved in the box and credited once the Wi-Fi or server comes back, never twice.
  • Kiosk lockdown on PCsWin key, Alt+Tab, Alt+F4 and Task Manager are blocked while a PC is locked.

Printable PCB for the coin box

An 80 × 64 mm board that replaces the breadboard or perfboard. Everything plugs into screw terminals and pin headers: 12 V in, the LM2596, the coin acceptor, the LED frame, SET and the ESP32. The circuit matches the bench-tested wiring guide.

  • Order itUpload the Gerber zip to JLCPCB, PCBWay or a similar maker. The defaults work: 2 layers, 1.6 mm, HASL. The minimum order is usually 5 boards.
  • Or etch it yourselfPrint the PDF at 100 % / Actual size (the bar must measure 50 mm), toner-transfer it onto single-sided copper board, etch and drill.

Get started

Set it up yourself.

No programming needed. The guide covers every step.

  1. Build and flash the coin boxWire it per the guide, then flash the ESP32 from Chrome with Espressif's web flasher. Nothing to install.
  2. Install the serverRun RentalSystem-Server-Setup.exe on your counter or diskless server PC. It sets up everything it needs.
  3. Install the PCsDiskless: install once in the image and give each PC a hostname. Traditional: run the client installer on each PC.
  4. Set up tablets (optional)Factory reset, install the APK, and lock it with one adb command.
  5. Set your prices and testChange the admin password, set rates, then drop a coin on a locked unit.

FAQ

Common questions

Is it really free? What's the catch?

There's no catch. It's free and open source under GPL-3.0. There's no license key, activation or monthly fee in the code, and the source is public so anyone can check it. We only ask one favor: if it helps your shop, star the GitHub repo. It helps other shop owners find Slotify and helps us start a support group.

Windows says "Windows protected your PC". Is it a virus?

That warning appears for any installer without a paid code-signing certificate. Click More info → Run anyway. You can verify each file with the SHA-256 hashes on the Releases page, and read the source code yourself.

Does it work without internet?

Yes. Everything runs on your shop's own network. All devices just need to be on the same router.

Will it work on my traditional (non-diskless) setup?

It should, but we've only tested it on iCafe8 diskless so far. If you try it, please send a tester report so we can confirm it or fix what breaks.

Can I use a different coin acceptor?

Only the Allan 1239A Pro Max is tested. Another acceptor needs a pulse output and an inhibit/SET input, programmed so pulses equal pesos on the SLOW setting.

What if two customers tap Insert Coin at the same time?

The first one gets the slot for up to 60 seconds. The other sees "coin slot in use" and taps again once it's free.

Does it run on Windows 7?

No. PCs and the server need Windows 10 or 11, 64-bit.

Can I sell it or modify it?

Yes, under GPL-3.0. If you share or sell a modified version, you must publish its source code under the same license.
