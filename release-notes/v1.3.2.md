# Slotify v1.3.2

**What's new since v1.3.1:**

- **PC lock screen tells the owner what's wrong.** If a PC can't reach the server for 30 seconds, the lock screen now shows a hint under "Please wait for connection." It says either that the server wasn't found on the network, or which server address it can't reach (is Slotify Server open? is Mosquitto running? is TCP 1883 allowed?). Before, a new owner only saw "Please wait for connection."
- **Auto-detect fix (PC client).** When `auto` can't find the server, the PC retries the last server it found instead of trying to connect to a server literally named "auto".
- **New (UNTESTED): Denz Customized's ready-made sub vendo board.** `coin-box-denz-merged.bin` runs the coin box on Denz's "Mini Wireless Sub Vendo Board" v2.0 with a 38-pin ESP32, with no soldering. Nobody has tried it on a real board yet: read [docs/hardware/denz-subvendo-board.md](https://github.com/rjcantare/Slotify/blob/main/docs/hardware/denz-subvendo-board.md) and do the bench test first. The normal `coin-box-merged.bin` hasn't changed.
- **Docs:** the owner guide now states the default admin password and how to change it (**Setup → Tablet Admin**, applies to PCs and tablets), plus a troubleshooting entry for a PC stuck on "Please wait for connection."

The server and tablet app have no functional changes; they're rebuilt with the new version number so the **Updates** button keeps everything on the same version.

Free, open-source centralized coinslot system for Windows pisonet and rental shops. There's one coin box for the whole shop, Windows PCs and Android tablets can be rental units, and everything runs on the shop LAN.

**Setup and wiring guide:** [docs/OWNER-GUIDE.md](https://github.com/rjcantare/Slotify/blob/main/docs/OWNER-GUIDE.md) · **Website:** https://rjcantare.github.io/Slotify/

## Files

| File | Install on |
|------|------------|
| `RentalSystem-Server-Setup.exe` | The one server PC (counter PC or diskless server). Install this **first**. |
| `RentalSystem-Client-Setup.exe` | Each rental Windows PC (or once in the diskless image) |
| `RentalSystem-Tablet.apk` | Each Android tablet or phone (Android 8.0+), set as Device Owner |
| `coin-box-merged.bin` | The ESP32 in the Slotify coin box (your own build or the Slotify board). Flash at address `0x0` with https://espressif.github.io/esptool-js/ |
| `coin-box-denz-merged.bin` | **UNTESTED.** The ESP32 on Denz Customized's sub vendo board. Same flashing steps. |
| `SHA256SUMS.txt` | Checksums for the files above |
| `RentalServer.exe`, `RentalClient.Windows.exe`, `update.json` | Used by the **Updates** button. You don't need to download these. |

## Updating from v1.3.1

Click **Updates** on the server. The PCs and tablets show an update badge and update in place. Coin boxes don't need reflashing (their firmware is unchanged).

## Before you install

- **Windows will warn "Windows protected your PC".** The installers aren't code-signed. Click **More info → Run anyway**. Check the files against `SHA256SUMS.txt` with `Get-FileHash .\<file>`.
- **Change the admin password right after setup.** The default is `admin@123!` and it's public. On the server, click **Setup → Tablet Admin**. It applies to the PCs and tablets.
- **Coin box Wi-Fi:** on first boot it opens the hotspot `Slotify-CoinBox-XXXX` (password `slotify-setup`). Connect a phone and pick your shop Wi-Fi.
- **Coin box updates are USB-only.** Wireless (OTA) updates are turned off in this public build.
