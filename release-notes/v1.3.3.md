# Slotify v1.3.3

**What's new since v1.3.2: Check Setup.** First-time owners can now find and fix connection problems themselves.

- **Server → Setup → Check Setup.** One click checks everything a new shop usually gets wrong, and gives a one-line fix for each problem (red **FIX** first, then orange **CHECK**):
  - **MQTT broker:** is Mosquitto installed and running, and is port 1883 reachable from the LAN (not only from the server PC)?
  - **Windows Firewall:** warns if the network is set to Public, and checks Slotify's TCP 1883 and UDP 5353 rules, with the exact command to add a missing one.
  - **Network:** the server's IP and the address PCs should use; warns about extra adapters (VPN, VirtualBox, Hyper-V) and about a server IP that changed after Slotify Server started.
  - **Auto-detect:** is the server announcing itself to PCs (LAN broadcast) and to tablets and the coin box (mDNS)?
  - **PCs, tablets and coin box:** how many are online, which are offline, and when each was last seen; the coin box's firmware version.
  - **Security:** warns if the admin password is still the public default.
- **Copy report.** Copies a short summary to paste in the Slotify Facebook group when asking for help. It has no passwords and no PC names.
- **PC lock screen hint** now tells the owner to run **Check Setup** on the server when a PC can't connect.
- **Owner Guide** troubleshooting now starts with Check Setup.

The tablet app and coin box firmware have no functional changes; they're rebuilt with the new version number.

Free, open-source centralized coinslot system for Windows pisonet and rental shops. There's one coin box for the whole shop, Windows PCs and Android tablets can be rental units, and everything runs on the shop LAN.

**Setup and wiring guide:** [docs/OWNER-GUIDE.md](https://github.com/rjcantare/Slotify/blob/main/docs/OWNER-GUIDE.md) · **Wiring diagrams:** https://rjcantare.github.io/Slotify/wiring.html · **Website:** https://rjcantare.github.io/Slotify/

## Files

| File | Install on |
|------|------------|
| `RentalSystem-Server-Setup.exe` | The one server PC (counter PC or diskless server). Install this **first**. |
| `RentalSystem-Client-Setup.exe` | Each rental Windows PC (or once in the diskless image) |
| `RentalSystem-Tablet.apk` | Each Android tablet or phone (Android 8.0+), set as Device Owner |
| `coin-box-merged.bin` | The ESP32 in the Slotify coin box (hand-wired or Slotify PCB). Flash at address `0x0` with https://espressif.github.io/esptool-js/ |
| `coin-box-denz-merged.bin` | **UNTESTED.** The ESP32 on Denz Customized's sub vendo board. Same flashing steps. |
| `SHA256SUMS.txt` | Checksums for the files above |
| `RentalServer.exe`, `RentalClient.Windows.exe`, `update.json` | Used by the **Updates** button. You don't need to download these. |

## Updating from v1.3.2

Click **Updates** on the server. The PCs and tablets show an update badge and update in place. Coin boxes don't need reflashing.

## Before you install

- **Windows will warn "Windows protected your PC".** The installers aren't code-signed. Click **More info → Run anyway**. Check the files against `SHA256SUMS.txt` with `Get-FileHash .\<file>`.
- **Change the admin password right after setup.** The default is `admin@123!` and it's public. On the server, click **Setup → Tablet Admin**. It applies to the PCs and tablets. Check Setup reminds you until it's changed.
- **Coin box Wi-Fi:** on first boot it opens the hotspot `Slotify-CoinBox-XXXX` (password `slotify-setup`). Connect a phone and pick your shop Wi-Fi.
- **Coin box updates are USB-only.** Wireless (OTA) updates are turned off in this public build.
