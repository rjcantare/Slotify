# Slotify v1.3.0: first public release

Free, open-source centralized coinslot system for Windows pisonet and rental shops. There's one coin box for the whole shop, Windows PCs and Android tablets can be rental units, and everything runs on the shop LAN.

**Setup and wiring guide:** [docs/OWNER-GUIDE.md](https://github.com/rjcantare/Slotify/blob/main/docs/OWNER-GUIDE.md) · **Website:** https://rjcantare.github.io/Slotify/

## Files

| File | Install on |
|------|------------|
| `RentalSystem-Server-Setup.exe` | The one server PC (counter PC or diskless server). Install this **first**. |
| `RentalSystem-Client-Setup.exe` | Each rental Windows PC (or once in the diskless image) |
| `RentalSystem-Tablet.apk` | Each Android tablet or phone (Android 8.0+), set as Device Owner |
| `coin-box-merged.bin` | The ESP32 in the coin box. Flash at address `0x0` with https://espressif.github.io/esptool-js/ |
| `SHA256SUMS.txt` | Checksums for the files above |

## Before you install

- **Windows will warn "Windows protected your PC".** The installers aren't code-signed. Click **More info → Run anyway**. Check the files against `SHA256SUMS.txt` with `Get-FileHash .\<file>`.
- **Change the admin password right after setup.** On the server, open **Tablet Admin Password**. The default `admin@123!` is public.
- **Coin box Wi-Fi:** on first boot it opens the hotspot `Slotify-CoinBox-XXXX` (password `slotify-setup`). Connect a phone and pick your shop Wi-Fi.
- **Coin box updates are USB-only.** Wireless (OTA) updates are turned off in this public build.

## Tested

- 12 Windows 10 PCs on iCafe8 diskless, Android tablets (including Xiaomi), one Allan 1239A Pro Max coinslot.
